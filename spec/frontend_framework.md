# Фронтенд-стек

Рекомендуемый набор инструментов для кабинетов. Слой — одна ответственность,
конфиг минимальный, типы и схемы общие для агента и человека.

Источник выбора: [`frontend_framework.jpg`](frontend_framework.jpg).

| Слой | Инструмент |
| --- | --- |
| Сборка | Vite + React 19 + TypeScript strict |
| Маршруты | TanStack Router, файловые маршруты |
| Данные | TanStack Query + типизированный API-клиент |
| UI | Tailwind + shadcn/ui |
| Чат и карта | assistant-ui, `@xyflow/react` + React Flow UI |
| Формы | zod + react-hook-form |
| Линт и формат | Biome или ESLint + Prettier |
| Тесты | Vitest + Testing Library; Playwright для e2e |
| Монорепо | pnpm workspaces + Turborepo |

## Сборка

**Vite**, **React 19**, **TypeScript** в режиме `strict`.

Vite почти не требует конфигурации. `tsc --noEmit` проходит за секунды: агент
сразу видит ошибки типов и правит сам. Нет границы server/client, которую
легко перепутать.

## Маршруты

**TanStack Router**, файловая схема.

Из имён файлов собирается типизированное дерево маршрутов. Агент следует
соглашению папок; неверная ссылка ломает компиляцию, а не только рантайм.

## Данные

**TanStack Query** и типизированный клиент API: GraphQL codegen или tRPC.

Явные конвенции, много примеров в обучающих данных. Сгенерированные типы не
дают выдумать поля, которых нет в контракте.

В этом репозитории клиент пока пишется вручную: в спецификации шлюза нет схем
тел. Ответ проверяется zod-схемами из `packages/contracts` через `safeParse`.
Генерация клиента — когда схемы появятся в шлюзе.

## UI

**Tailwind** и **shadcn/ui**.

Компоненты лежат в репозитории: агент читает исходник, а не непрозрачный пакет.
У shadcn есть официальный MCP-сервер: агент сам просматривает каталог и
добавляет компоненты.

- Документация: https://ui.shadcn.com
- Настройка Claude Code: https://ui.shadcn.com/docs/cli

## Чат и карта

**assistant-ui** — диалог с агентом.

**`@xyflow/react`** и **React Flow UI** — граф и карта работ.

Тот же принцип, что у shadcn: код копируется в репозиторий. React Flow UI
ставится через CLI shadcn, поэтому тот же MCP покрывает и его.

## Формы и валидация

**zod** и **react-hook-form**.

Одна схема на клиент и API. Форма и контракт не расходятся: агент не может
завести разные формы одних и тех же полей.

Общие схемы — в `packages/contracts`, их тянут web, api и агенты.

## Линт и формат

**Biome** (один инструмент, один конфиг) либо связка **ESLint + Prettier**.

Детерминированно и быстро. Запускать хуком после каждого правки, чтобы
сломанный код не переживал ход агента.

## Тесты

**Vitest** и **Testing Library** — юнит и компоненты.

**Playwright** — e2e. У Playwright есть MCP: агент открывает браузер и смотрит
экран, а не только логи.

Агенту нужна проверка «готово»: тесты — способ это доказать.

## Монорепо

**pnpm workspaces** и **Turborepo**.

`packages/contracts` с zod-типами — единственный источник истины для web, api
и агентов. Монорепо в `portal/demo` — pnpm workspaces и Turborepo.
